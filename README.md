# 電子工学 後期中間テスト対策サイト

後期中間プリント（問題Ⅰ～Ⅶ）と授業ノート（5.4 hパラメータ ～ 7.3 OPアンプの使い方）の範囲をすべて網羅した自習用サイトです。ビルド不要の静的サイト（HTML / CSS / JavaScript）です。

## 機能

| ページ | 内容 |
| --- | --- |
| まとめ | 範囲全体の要点ノート（回路図・図記号・断面図・波形はすべて SVG で描画）と公式一覧 |
| 演習プリント | 問題Ⅰ～Ⅶを本番と同じ形式で再現。入力してまとめて採点、解説つき |
| 予想問題 | ノートだけに載っている内容（hパラメータ計算、J-FET特性、MOSFET、CMOS、OPアンプ特性、正相増幅回路）から作成 |
| 一問一答 | 全問題（穴埋めは1空欄ずつ）から分野・形式を選んで出題 |
| 計算ドリル | g<sub>m</sub>、hパラメータ増幅度、正相増幅回路、dB 変換、差動出力を数値ランダムで出題 |
| 模擬テスト | プリント＋予想問題＋計算からランダムに出題、時間制限・分野別成績つき |
| 苦手復習 | 直近で間違えた問題だけを出題 |

○×・選択問題は押した瞬間に採点されます（模擬テストだけは提出時にまとめて採点）。記号・数式が答えになる問題（h パラメータ記号、v<sub>o</sub>=v<sub>o1</sub>−v<sub>o2</sub>、∞ など）は「答えを見る」→「○ 合ってた／× 違った」の自己採点です。計算問題も「入力せずに答えを見て自己採点」できます。

学習記録はブラウザの localStorage に保存されます（端末ごと）。

## GitHub Pages で公開する手順

1. このフォルダの内容をコミットして GitHub に push する
2. リポジトリの **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」、**Branch** を `main` / `/ (root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/electronic_manufacturening/` で公開される

## ローカルで確認する

```bash
python3 -m http.server 8765
```

ブラウザで http://localhost:8765 を開く。

## ファイル構成

- `index.html` … ページの枠
- `style.css` … デザイン（ライト / ダーク対応）
- `js/figures.js` … 図（SVG）の生成
- `js/data.js` … 問題データ（演習プリント・予想問題・計算ドリル）
- `js/notes.js` … まとめノート・公式一覧
- `js/app.js` … 画面切替・採点・クイズ・模擬テスト

問題を追加・修正したいときは `js/data.js` を編集してください。記述問題は `acc` に別解を追加すると正解として判定されます。
